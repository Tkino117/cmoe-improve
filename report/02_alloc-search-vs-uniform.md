# 02 層ごとに探した配分は、一様配分に勝つか（seed 1本の下見）

2026-08-19 / 実験 `experiments/04_h1h3_pilot/` / 出力 `result_logs/h1h3_pilot/`

## 目的

「探索した配分はどの一様配分よりも PPL が低い」を、一様 x=0〜6 の対照（H1）、wikitext2 で校正した探索（H2）、
c4 で校正した探索（H3）として **seed 1本**で通した下見。

## 設定

| | |
|---|---|
| モデル / 層数 | `meta-llama/Llama-2-7b-hf` / 32 |
| N（expert 数）/ A（1トークンあたり） | 8 / 6（全構成で同一） |
| 校正 | 8本 × 2048トークン、seed 0 |
| 探索 | beam（幅 2 / 3 / 4）× オラクル `suffix_kl` |
| ルーター / 分割 | 現行 CMoE（k_act 10 / bias_speed 0.001） |
| 環境 | RTX PRO 5000 Blackwell、Python 3.11.14 / PyTorch 2.8.0+cu128 / transformers 4.47.1 |
| コード | `4961c47` + 本実験のスクリプト |

配分を探す文章①とモデルを組む文章②は**同じ8本に揃えた**（docs/03 の指定。
report/01 は②を固定して①だけを振っていた）。切り分けに使う文章と点数を測る文章は
完全に別で、評価文章はどの構成でも同一。

## 結果

同じ校正データで組んだ一様配分と探索配分をまとめて並べる。校正が変わればモデルの
組み方も変わるので、左右2組は直接は比べられない。

## 保存されているもの

`result_logs/h1h3_pilot/`（2.0MB）。探索は全層 × 全親 × 全候補のスコアと落選枝を
含む系譜（`h*_search_w*/search.json`）、評価は**塊単位の平均 NLL を全件**と全引数
（`*/summary.json`）。集約は `pilot.json` / `pilot.md`。対応のある比較や信頼区間は、
この塊単位 NLL から GPU なしで後から計算できる。
