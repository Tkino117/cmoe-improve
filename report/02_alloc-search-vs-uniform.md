# 02 層ごとに探した配分は、一様配分に勝つか（seed 1本の下見）

2026-08-19 / 実験 `experiments/04_h1h3_pilot/` / 出力 `result_logs/h1h3_pilot/`

## 目的

CMoE は各層の FFN を8個の expert に切り分け、1トークンあたり6個を走らせる。その
うち x 個が常時オン（shared）、残り 6−x 個をルーターが選ぶ。**x を層ごとにどう
配っても計算量は変わらない**ので、比べているのは同じコストの使い道である。

[docs/03](../docs/03_expermient-design.md) の主張「探索した配分は**どの**一様配分
よりも PPL が低い」を、一様 x=0〜6 の対照（H1）、wikitext2 で校正した探索（H2）、
c4 で校正した探索（H3）として **seed 1本**で通した下見。有意性は主張しない。

## 設定

| コード | `4961c47` + 本実験のスクリプト |

配分を探す文章①とモデルを組む文章②は**同じ8本に揃えた**（docs/03 の指定。
report/01 は②を固定して①だけを振っていた）。切り分けに使う文章と点数を測る文章は
完全に別で、評価文章はどの構成でも同一。

## 結果

### PPL

同じ校正データで組んだ一様配分と探索配分をまとめて並べる。校正が変わればモデルの
組み方も変わるので、左右2組は直接は比べられない。

| 配分 | 平均 x | 校正 wikitext2 → wt2 | → c4-new | 校正 c4 → wt2 | → c4-new |
|---|---|---|---|---|---|
| uniform0 | 0.00 | 29.378731 | 26.780499 | 19.587965 | 26.104303 |
| uniform1 | 1.00 | 7.394275 | 10.472202 | 7.857100 | 10.261037 |
| uniform2 | 2.00 | 7.175551 | 10.282352 | 7.791920 | 10.039412 |
| uniform3 | 3.00 | 7.071955 | 10.236954 | 7.699692 | 9.998899 |
| uniform4 | 4.00 | **6.958056** | **10.219474** | **7.657051** | 9.984110 |
| uniform5 | 5.00 | 6.965264 | 10.311577 | 7.779462 | 10.027929 |
| uniform6 | 6.00 | 7.045379 | 10.450652 | 8.024898 | 10.154963 |
| beam 幅2 | 4.09 / 4.41 | 6.965592 | 10.291927 | 7.830888 | 9.981521 |
| beam 幅3 | 3.72 / 4.50 | 6.943663 | **10.198288** | 7.763735 | 9.948374 |
| beam 幅4 | 3.97 / 4.28 | **6.930277** | 10.245705 | 8.047213 | **9.943365** |

太字は列の最小値。平均 x の2つの値は wikitext2 校正 / c4 校正。

- 一様配分の最小はどの列も x=4
- wikitext2 校正では wt2 の PPL が幅2→3→4 で 6.965592 → 6.943663 → 6.930277 と下がり、
  最良の一様（6.958056）を幅3・幅4 が下回った。c4-new では幅3（10.198288）のみが下回った
- c4 校正では c4-new の3本すべてが最良の一様（9.984110）を下回った。一方 wt2 では
  3本とも一様配分より高い
- c4 校正のモデルは x=1〜6 で wt2 の PPL が高くなる（uniform3 で 7.071955 → 7.699692）。
  uniform0 だけは逆に 29.378731 → 19.587965 と低い

差の大きさは最大でも wt2 で 0.027779、c4-new で 0.040745 であり、report/01 が測った
seed 間の標準偏差（PPL で 0.025524 / 0.032590）と同程度である。

6本すべて相異なる。幅どうしの一致の仕方は校正で違い、wikitext2 校正は3本共通が層0
だけ（幅2 が層1、幅3 と幅4 が層2 で分岐）、c4 校正は**層0〜11 が3本とも一致**し、
幅4 が層12、幅2 と幅3 が層21 で分かれる。x=6 の層（ルーターが出力に効かない層）は
wikitext2 校正で 9 / 4 / 6、c4 校正で 7 / 7 / 6。x=0 の層は各1〜2。
