# 08 スパース率50%で、配分探索を seed 3本で測る

2026-08-26 / 実験 `experiments/07_sparsity50/` /

## 目的

[report/07](07_slimpajama-alloc-3seeds.md)（N=8 / A=6、スパース率25%、seed 3本）は
**PPL では3対照すべてに勝ち、ベンチでは検出できなかった**。効果量が `acc` で
0.005 程度・区間の半幅が ±0.005 で、seed 3本では桁が足りないことも同時に書いた。

ここは**動作点だけを厳しくする**。A=6 → A=4 で、1トークンあたりに走る expert が
8個中4個になり、捨てるぶんが 25% → 50% になる。配分の効き目が伸びればベンチでも
見える。

**A 以外は report/07 と1つも変えていない。** 校正・オラクル・探索・ルーター・
分割・評価セット・ベンチ・ブートストラップ・判定の枠組みまで同じである。校正
トークンのハッシュが report/07 と一致する（下記）のがその確認になる。

**言わないこと。** report/07（25%）との差そのものには統計判定を当てない。別の
実行・別の動作点で、対応の取れる単位（同じ問題・同じ塊の上の差）が無いためで、
25%の数字は記述として並べるだけにする。

## 効き目の限界

- ブートストラップが再抽出するのは評価塊と問題であって、**seed ごとに配分ベクトル
  が変わるぶんの分散は3本では測れない**。そこを補うのが per-seed の符号一致
  （表の括弧）で、主役の幅4 の `gold_nll` がまさにそこで 2/3 に留まった
- ベンチの効果量は対等な対照に対して `acc` で +0.004、区間の半幅が ±0.0045 で、
  **25%のときと同じ桁である**。`gold_nll` のように連続な指標では動作点を厳しく
  した効果が出たが、正答率は依然として標本誤差に埋もれている
- **対照3種のうち2種が同じものになった**。校正も評価指標も3 seed のほぼすべてで
  `uniform4` を選んだため、「校正で選んだ一様」と「評価指標で最良の一様」の
  差が今回は見えない（25%では割れていた）
- 一様の格子の下端は実質的に使えない。`uniform0` は PPL 5442、`acc` 0.371 で
  壊れており、`uniform1` も一様の中で最下位に近い
