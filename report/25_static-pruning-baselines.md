### スパース率の定義

MoE 変換は全パラメータを保持したまま実行だけを疎にし、静的プルーニングは重みを
削除する。揃えられるのは**トークンあたりの活性パラメータ**だけである。共通軸は
ブロック（attn+FFN）に対する実効削減率で、Llama-2-7B の1ブロックは
FFN `3·d·i` = 135.3M、attention `4·d²` = 67.1M。

提案手法の 25%（N=8 / A=6）は FFN ニューロンの比なので、ブロック全体では
`(1 − A/N)·3di/(3di+4d²)` = **16.71%** である。一方 FLAP の `pruning_ratio` は
attn+FFN 全体に対する比、LLM-Pruner の `pruning_ratio` は刈る層の中でのチャネル比
（既定は層 4〜29 の 26 層のみ）。`--scope` で2つの土俵を測る。

| `--scope` | 定義 |
|---|---|
| `block` | 原典の定義そのまま |
| `mlp` | FFN だけを刈り、削る FFN ニューロンの割合を提案手法に揃える |

### 移送

公式実装は自前の `modeling_llama.py`（LLM-Pruner はさらに同梱の `torch_pruning`）に
依存し、このリポジトリの transformers 4.47.1 と共存しない。統計と規則のみを移した。

**FLAP**（`--metrics WIFV --structure AL-AM`、CASIA-IVA-Lab/FLAP の `prune_flap`）:
入力チャネルごとの平均とゆらぎを刈る前のモデルで層ごとに貯め、
`WIFV = fluc × Σ_out W²`（attention 側は2乗）を層ごとに標準化、全層・全構造を
パラメータ数で重み付けした累積で切り、落としたチャネルの平均寄与を出力側の bias に
移す。公式の `compression_weight` は int64 テンソルに `512.0/3` を代入して 170 に
切り捨てられるため、ここは浮動小数のまま使う（目標スパース率が 0.4% ずれる）。
ゆらぎの式は公式の `BiasGPT` と `baseline_inp` / `fluc_inp` / WIFV とも差 0 を確認
（`tests/test_prune.py`）。

**LLM-Pruner**（`--block_wise --pruner_type taylor --taylor param_first`、
horseee/LLM-Pruner）: FFN 群 = `Σ|W_gate·G_gate| + Σ|W_up·G_up| + Σ|W_down·G_down|`、
attention 群 = q/k/v/o の同項をヘッド内で総和。刈る本数は原典の `C − int(C·(1−s))`。
層範囲は公式スクリプトの既定 4〜29。**追加学習（LoRA recovery）は行わない。**
勾配は bf16 で取り、総和のみ fp32（原典は fp32 / CPU）。
