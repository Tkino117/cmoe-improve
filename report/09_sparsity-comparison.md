## 何を並べるか

[report/07](07_slimpajama-alloc-3seeds.md)（N=8 / A=6、スパース率25%）と
[report/08](08_sparsity50-alloc-3seeds.md)（N=8 / A=4、スパース率50%）は、
**A 以外の設定が同一**である（Llama-2-7B / 32層、slimpajama n=16 校正の seed
0/1/2、`suffix_kl` × beam 幅2/3/4、現行 CMoE ルーター、同じ5タスクのベンチ）。
校正トークンのハッシュも両者で一致する。

ここでは「どのような配分が導かれたか」と「ベンチマークのマクロ平均がどうだったか」
の2点だけを、既に測ってある数字から並べる。**判定は当てない**（別の実行・別の
動作点で、対応の取れる単位が無い）。個々の統計判定は report/07・08 にある。

配分の x は「その層で常時使う shared expert の数」で、routed の Top-K は A − x に
なる。x = A の層は Top-K = 0、つまりその層は routing をしない。
