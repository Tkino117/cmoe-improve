# 21 ExpertWeaver の配分規則を対照として測る — 平均 x を揃えると差が消える

2026-09-03 / 実装 `src/cmoe/alloc/ew_rule.py`・`experiments/21_ew_rule/` /
出力 `result_logs/ew_probe_*`、`result_logs/ew_bench{,_a4}_seed{0,1,2}`

## 問い

配分の決め方を比べる論文に、**規則ベースの対照が1本も無かった**。対照は
「校正が選んだ一様」と「層ごとに独立に確定する貪欲」しかなく、どちらも
先行研究の手法ではない。

ExpertWeaver (arXiv:2602.15521) は層別配分を提案した唯一の先行研究である。
ただし多タスク校正・balanced K-Means による expert 構築・gate セントロイドの
ルーターを同時に持つので、そのまま並べると4つの違いが混ざる。

**配分を決める式だけを取り出して、現行 CMoE の分割・ルーターの上に載せたら
どうなるか。** それが答えられれば、比べているのが配分軸だけになる。

## 移せる理由

EW §3.2 は「全 N_se,ℓ 個の共有 + ルーターが選ぶ上位 k−N_se,ℓ 個、トークン
あたり合計 k 個」と置いている。これは ``x_ℓ + K_ℓ = A`` そのもので、**予算の
不変性がこちらと同一**である。配分だけを差し替えても土俵が崩れない。

規則は3段（式 4・5・6）:

1. ``a_ij`` = サンプル j のトークン平均 ``Swish(g_i·x)``
2. ``CV_i`` = サンプル方向の変動係数、``r_ℓ`` = ``CV_i > τ`` の割合
3. ``α_ℓ = α_max − (α_max−α_min)·r_ℓ``、``x_ℓ = round(α_ℓ·N)``

**原論文から違えたのは3点で、いずれも ``ew_rule.py`` の冒頭に書いてある。**
サンプルの単位（Flan の1例 → 128トークン窓。本数は M=256 で EW の 240 に対応）、
粒度（expert 64 → 8）、``[0, A]`` へのクリップ。ハイパーパラメータは EW §4.1 の
既定値 τ=0.6・α∈[0.2, 0.7] をそのまま使う。**掃引はしない** — 既定値は EW 自身が
評価ベンチ上で調整した値であり、そのまま使うことが EW を最も有利に扱うことになる。

## 結果0: 既定値を素朴に移すと、必ず一様配分へ縮退する

最初の実装は CV を**活性の絶対値**で取っていた（Swish は負を取るので、平均が
0 近傍のニューロンで CV が発散するのを避けるため）。これで τ=0.6 は一度も
噛まなかった。

| 校正 | サンプル長 | M | r_ℓ の範囲 | 出た配分 |
|---|--:|--:|---|---|
| slimpajama | 2048 | 16 | 0.001–0.033 | 32層中31層が x=6 |
| flanv2 | 2048 | 16 | 0.000 | 全層 x=6 |
| slimpajama | 128 | 256 | 0.002–0.039 | x ∈ {5, 6} |
| flanv2 | 128 | 256 | 0.001–0.012 | 全層 x=6 |

**多タスク校正は原因ではない。** flanv2 の方が一貫して縮退が強い —
`data/flanv2.py` はタスクをラウンドロビンしてから窓を切るので、多タスク性が
窓の**中**に入り、トークン平均で消える。

原因は絶対値だった。Swish は負側が −0.278 で下げ止まるので、めったに活性
しないニューロンはトークン平均が 0 近傍になり CV が発散する。**その発散が
「特化」の検出そのもの**で、`|·|` を取ると平均に正の下駄が入って分布が
0.1 付近に潰れる。EW §3.3 の「絶対値付き平均活性化スコア」は shared **の
選択**の話であって、CV の定義ではない。

符号付きに直すと τ=0.6 が効き、`r_ℓ ∈ [0.61, 0.96]` になった。
**縮退した4本も `result_logs/` に残してある** — 「素朴に移すと縮退する、
原因は符号である」は再現手順ごと記録する価値がある。

- **seed 0 と 2 は完全一致**、seed 1 が2箇所違うだけ。探索が seed で動く
  （res09: 平均 x が 4.41 / 4.66 / 4.75）のに対し、**規則は seed に対して

- 出る x は2値（中間層が 3、両端が 2）で、層別といっても分解能は低い。

## 結果3: 平均 x を揃えると差が消える（ここが本題）

**結果2 だけでは「規則が悪い」と言ってはいけない。** EW-rule の平均 x は 2.41、
対照は探索が 4.41、校正が選んだ一様が 5〜6 で、そもそも動作点が違う。負けが
規則の質なのか、既定 α が出す x の位置なのかを分けるには、**平均 x が同じ一様**と
比べるしかない。追加測定は要らない（`uniform2` / `uniform3` は測ってある）。

**対 `uniform2`（EW-rule の平均 x = 2.41 の直下）**

| 指標 | 25% | 50% |
|---|---|---|
| `acc` | −0.003762 [−0.008570, +0.001157] | +0.003587 [−0.001662, +0.008680] |
| `acc_norm` | +0.000401 [−0.004410, +0.005144] | +0.002834 [−0.002437, +0.007854] |
| `gold_nll` | −0.013250 [−0.032167, +0.005479] | **−0.051678 [−0.080772, −0.022519]*** |
| `margin` | +0.013672 [−0.018021, +0.044970] | **+0.067702 [+0.029155, +0.107583]*** |
| `ref_agreement` | −0.001225 [−0.006421, +0.003964] | −0.000414 [−0.005878, +0.004999] |

**25% では6指標すべての区間が0をまたぐ。** 50% でも `acc` / `acc_norm` /
`ref_agreement` は差が無く、親モデルへの忠実度（`gold_nll` / `margin` /
`ref_kl`）だけがわずかに EW-rule 側へ振れる。

一方 `uniform3`（平均 x の直上）に対しては、25% で `gold_nll` +0.0569*、
50% で `acc` −0.0116* と、EW-rule が負ける。

## 観察

1. **EW-rule の層別構造は、平均 x を超える寄与をしていない。** 25% では
   `uniform2` と統計的に区別できない。層ごとに x を変えているのに、同じ平均の
   定数配分と同じ成績になる。
2. **負けの大部分は動作点の選択で説明できる。** 既定 α∈[0.2, 0.7] は N=8 では
   x を 2〜3 にしか落とさない。25% で校正が選ぶ一様は 5〜6、50% では 4 なので、
   規則は良い x から遠いところを指している。
3. **規則は seed に対して安定だが、そのぶん校正データに適応していない。**
   3 seed でベクトルがほぼ一致するのは、CV の分布が校正の引き直しでほとんど
   動かないためである。探索は seed ごとに違う配分を出す。
4. **既定値を移植すること自体に落とし穴がある（結果0）。** τ は CV の絶対値
   スケールに対するしきい値で、そのスケールは活性の取り方・サンプルの単位・
   モデルで動く。τ=0.6 が Qwen2.5-7B / N_e=64 / Flan の1例で意味を持っても、
   別の設定へそのまま運べるとは限らない。

## 考察・結論

**対照としては成立した。** 予算の不変性が共通なので比較は公平で、6本すべてで
既存測定をビット単位で再現している。EW-rule は両スパース率で校正が選んだ一様に
負け、探索にも負ける。

**ただし論文で「EW に勝った」と書いてはいけない。** 結果3 が示すのは
「EW-rule ≈ 同じ平均 x の一様配分」であって、規則の層別構造が害を成している
わけではない。正しい主張は次の2つである。

* **EW の規則は、こちらの動作点では良い平均 x を指さない。** 既定の α が
  N=8 という粒度に合っていない。これは res13 の「最良の x は評価データ・指標で
  動く」と同じ話で、**規則+定数では動作点を当てられない**という主張の実例になる。
* **この粒度では、規則が出す層別配分が定数配分と区別できない。** 平均 x を
  揃えると一様配分に戻る。ただし**これを「層別配分は効かない」と読んではいけない**
  — EW-rule が出す x は {2, 3} の2値しかなく、規則の表現力が N=8 で潰れている
  疑いがある（「残っている穴」を見ること）。res15 の「層間の依存は探索でないと
  捉えられない」を補強する材料**候補**であって、まだ証拠ではない。

## 残っている穴

* **τ・α を校正データ上で選び直した行が無い。** 「既定値が悪いだけで、規則族の
  最善なら勝てるのでは」に今は答えられない。`cmoe score --oracle suffix_kl` で
  格子（τ 9通り × α 3通り、`allocate.py --grid` が出す）を採点すれば埋まる。
  **観察2 が動作点の話に帰着している以上、査読でここは必ず突かれる。**
* **EW の分割（balanced K-Means）とルーター（gate セントロイド）は載せていない。**
  この論文の主張には要らないが、「EW 全体には勝っていない」ことは明記が要る。
* **平均 x を揃えた対照は `uniform2` / `uniform3` の2点しかない。** 2.41 に
  対応する非整数の一様は作れないので、この2点で挟む形になっている。x=2 と
  x=3 の間で成績が線形に動く保証は無いので、内挿は目安にしかならない。
* **粒度 N=8 が規則を潰している可能性がある（最重要）。** EW-rule が出す x は
  実際には **{2, 3} の2値だけ**で、この配分は「`uniform2` の層と `uniform3` の
  層の混合」そのものである。その2つを超えられないのは、ある意味で当然である。

  原因は expert 粒度である。EW の既定 α∈[0.2, 0.7] は N_e=64 前提で、そこでは
  x ∈ [12.8, 44.8] を細かい分解能で使える。N=8 では `round(α·8)` が {2,…,6} に
  潰れ、実際の CV 分布からは {2, 3} しか出てこない。

  **したがって結果3 は「層別配分という考えが効かない」ことの証拠にはならない。**
  言えるのは「N=8 では EW の規則が層別配分をほとんど表現できず、結果として
  同じ平均 x の定数配分と区別が付かない」までである。論文でこの区別を曖昧に
  すると、査読で正面から崩される。埋めるなら S6A6E16（TODO の「expert 粒度を
  上げる」）の上で EW-rule を測り直すのが筋で、そこは N_e=16 なので x の
  分解能が倍になる。
