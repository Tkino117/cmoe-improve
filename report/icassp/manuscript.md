## イントロ

### 1. 分野の背景

大規模言語モデルの推論コストは、その実用化における主要な制約となっている。この制約を緩和する有力な方向の一つが、Mixture-of-Experts (MoE) による条件付き計算である。しかし既存の MoE モデルは大規模な事前学習を前提としており、既に学習済みの dense モデルを MoE 化するには、通常は多大な再学習コストを要する。そこで近年、再学習を伴わずに dense モデルを MoE へ変換する training-free なアプローチが提案されている [CMoE など]。これらは FFN の重みを n 個の expert に分割し、推論時にはそのうち k 個のみを起動することで、総パラメータ量を保ったまま実効的な計算量を削減する。勾配計算を一切必要とせず、少量の校正データのみで完結するため、再学習の敷居が高い大規模モデルに対して特に実用的な意義を持つ。

### 2. 課題

しかし、この系統の手法には、性能を左右するパラメータの多くを経験的な設定に頼っているという共通の課題がある。たとえば、各層で常時起動する shared expert と選択的に起動する routed expert の配分は、層による役割の差異が考慮されないまま全層一律の値として与えられる [CMoE]。層ごとの配分を導入した ExpertWeaver [EW] でも、その探索範囲を規定するパラメータ自体は経験的に設定されており、結果はその設定に依存する。

これは、校正データを分割やルーティングの根拠となる統計量の算出にのみ用い、構成された結果を評価して決定に反映させる過程を持たないことに起因する。構成手続きが一方向であるため、残された設計判断は代理指標か人手の調整で埋めるほかない。

### 3. 実験による観察

実際、shared/routed の一様配分が最良となる値は評価データによって異なり、単一の固定値が普遍的に最適とはいえない。かといって、より良い代理指標を設計すればよいわけでもない。層ごとに独立に最適な配分を選ぶ素朴な貪欲法は一様配分に対して明確な改善をもたらさない一方、探索時に保持する配分候補の数を増やすほどオラクルのスコアは改善する傾向がある。これは、ある層の配分の良し悪しが他の層に依存するという、局所的な指標では捉えきれない層間の相互作用を示唆する。

したがって、この問題は代理指標の改良では解決されず、構成の結果を実際に評価しながら決定する手続きを要する。training-free な変換の設定では、その評価は手元の校正データ上の perplexity として直接測定できる。

### 4. 提案

本論文では、この観察に基づき、層別 shared/routed 配分を経験的に決定するのではなく、校正データ上の目的を直接最適化する探索問題として定式化する。推論時に起動する expert の総数を固定した制約のもとで、校正データ上の perplexity を最小化する配分を beam search により探索する。層間の相互作用を捉えるため、層ごとに独立に確定させるのではなく、複数の配分候補を保持したまま層を進める。

この探索は、性能を左右する経験的なしきい値を新たに導入しない。調整対象は探索の予算のみであり、これは計算量と性能の間の単調なトレードオフとして扱える。探索は変換時に一度だけ実行するため、**推論時の計算量は増加しない**。重みの値自体は変更せず構成のみを決定するため、fine-tuning とは競合せず、その前段として併用できる。

### 5. まとめ

本論文の貢献は以下の通りである。

- training-free な MoE 変換における層別 shared/routed 配分を、経験的な設定に代えて校正データ上で直接最適化する設計変数として定式化する。
- 層間の相互作用を捉える beam search による配分探索アルゴリズムを提案する。
- 複数の評価データにおける一貫した改善を確認し、fine-tuning との併用可能性を示す。

## 手法

### 1. 準備: CMoE 型の dense-to-MoE 変換

CMoE は、学習済みの dense モデルの FFN 層を、追加学習なしに MoE 化する。各層の FFN において、校正データに対する各ニューロンの活性化頻度を測り、頻度の高い上位のニューロンを shared expert として全トークンで常時起動させる。残りのニューロンは活性化パターンが似たものどうしでクラスタリングし、N_r 個の routed expert に分割する。各 routed expert について、そのクラスタの重心に最も近いニューロンを代表ニューロンとして選び、対応する重み列だけを残した縮約ゲートでルータースコアを近似する。推論時には、このスコア上位 Top-K の routed expert だけを追加で起動する。総パラメータ数は dense モデルと同一のまま保たれ、1 トークンあたりに実際に計算される expert 数、すなわち shared 数 x_ℓ と routed の Top-K_ℓ の和 A = x_ℓ + K_ℓ は、全ての層で共通の値に固定される。

配分 x_ℓ（0 ≤ x_ℓ ≤ A）は層ごとに独立に選べる自由度だが、CMoE は全層で同一の値 x_ℓ = x を用いる。層ごとの配分を導入した ExpertWeaver も、その決定に使う探索範囲のしきい値パラメータ自体は経験的に固定したままである。以降では、この配分ベクトル x = (x_1, ..., x_L) を校正データから直接決定する問題として定式化する。

### 2. 配分探索の定式化

配分 x_ℓ の良さは、変換後のモデルの出力分布が dense モデルの出力分布からどれだけ乖離するかで測るのが自然である。各層の出力誤差のような層ローカルな指標は、その層だけを見て、生じた誤差を後続の層が吸収するのか増幅するのかを言えない。3節の観察が示すように、層間にはこの伝播を無視できない相互作用がある。

そこで、層 0 から ℓ までを配分 (x_1, ..., x_ℓ) で変換した MoE とし、残りの層 ℓ+1 以降は dense のまま実行して得られる出力分布を P_接頭辞、完全な dense モデルの出力分布を P_dense とし、校正データのトークン平均 KL ダイバージェンス

  score(x_1, ..., x_ℓ) = Σ_t KL( P_dense(t) ‖ P_接頭辞(t) ) / T

を接頭辞のスコアとする。残りの層を dense で置き換える仮定を含むため、これは ℓ < L-1 では見積もりに過ぎず、ℓ = L-1（全層決定後）でだけ、実際に配備されるモデルの KL と一致する。目的は、各層で A 個の expert を起動するという制約 x_ℓ + K_ℓ = A（∀ℓ）のもとで、この最終スコアを最小化する配分 x* を求めることである。

### 3. beam search による探索

上記の目的関数を層 0 から順に評価しながら、良い接頭辞を幅 B 本だけ残して層を進める beam search により x* を近似する。層 ℓ では、幅 B 本の接頭辞それぞれについて次候補 x_{ℓ+1} ∈ {0, ..., A} をすべて試して子を作り、子をスコアで並べ替えたのち上位 B 本だけを残して層 ℓ+1 に進む。この操作を L 層分繰り返した末に残る 1 本を最終的な配分として出力する。ある層で捨てられた接頭辞は、以降どれだけ良い枝を持っていても復元されない。B=1 のときは、各層でその場のスコアが最良の 1 本だけを残す貪欲な歩き方に退化する。3節で観察した貪欲法の失敗は、この幅の下限に相当する。

子 1 つの評価は、その子から残りの層を dense として走らせる forward を要するため、層 ℓ の子 1 つあたりのコストは L-ℓ に比例する。したがって全体のコストは幅 B・候補数 A+1 に対して線形、層数 L に対しては L² のオーダーで増える。B は探索の予算そのものであり、増やすほど良い配分を見つけやすくなる一方、この計算コストとのトレードオフになる。

### 4. 性質

この探索は、CMoE や ExpertWeaver が導入していたような、性能を左右する新たな経験的しきい値を一切導入しない。唯一の調整対象は探索の予算 B であり、計算量と発見される配分の質との単調なトレードオフとして扱える。探索はモデル変換時に一度だけ実行され、得られる配分自体は CMoE と同じ形式の expert 構成であるため、**推論時の計算量やパラメータ数は変化しない**。また、この手続きは既存の重みの値を一切変更せず構成のみを決定するため、fine-tuning による後段の調整とは独立に適用でき、両者は競合しない。
