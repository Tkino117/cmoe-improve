# 論文用 抜き出し: 最良の一様配分は一つに定まらない（report/13）

出どころ [report/13](../13_^shared-ratio-diagonal.md) /
`result_logs/bench_shared_{piqa,winogrande,arc,hellaswag}_{uniform3,uniform5,uniform6}_seed{0,1,2}`、
`S4A2E8` の行は [report/12](../12_^calib-task-matrix.md) の対角
（`result_logs/bench_calibtask_*_seed{0,1,2}`）/ 新しい測定は無い

**イントロ §3 前半（「最良となる配分は評価データによって異なり、単一の固定値が
普遍的に最適とはいえない」）の根拠。** res16 の一様行も同じことを言うが、こちらは
x だけを動かすために組んだ実験なので交絡が少ない。

## 設定

| | |
|---|---|
| モデル / 層数 | `meta-llama/Llama-2-7b-hf` / 32 |
| N / A | 8 / 6（スパース率25%） |
| 配分 | `uniform3` / `uniform4` / `uniform5` / `uniform6`（= S3A3E8 / S4A2E8 / S5A1E8 / S6A0E8）。**x をどう変えても1トークンあたりに走る expert 数は 6 で同じ** |
| 校正 | **対角のみ**。評価タスクの train split から 8本 × 2048トークン、seed 0 / 1 / 2 |
| ルーター / 分割 | 現行 CMoE（k_act 10 / bias_speed 0.001）。**固定 Top-K** |
| 評価 | PIQA / WinoGrande / ARC / HellaSwag、0-shot・全件。ARC は e + c を束ねた1タスク |
| 実験 | `experiments/12_shared_ratio_diagonal` |

配分以外（校正セット・動作点・ルーター・評価・dense の基準）は report/12 と同一で、
**動かしたのは x だけ**である。

`x = A` のとき Top-K = 0 になり、ルーティングが消えて A/N のニューロンを常時使う
静的マスクに退化する。つまり `uniform6` は「枝刈りの退化ケース」であり、
**この列に負けたら routing を入れた意味が無い**という下限を兼ねている。

PPL では x=6 が両データセットとも最悪で、最良は x=3〜4。**`acc` が選ぶ x（5〜6）と
PPL が選ぶ x（3〜4）が食い違う**ので、「1つの定数」を置く余地がないことがここでも出る。

## 補強に使える隣接データ

- **校正が選ぶ一様も seed で動く。** report/07 で一様 x=0…6 を `suffix_kl` で採点
  すると、選ばれるのは seed 0 → `uniform6`、seed 1 → `uniform5`、seed 2 →
  `uniform6`（25%）。校正データを引き直すだけで最良の定数が変わる。
- **res16 の一様行**（5タスク + MMLU、25%）では、macro `acc` の最良が `uniform5`、
  macro `gold_nll` の最良が `uniform6`、MMLU 単体の最良が `uniform3` と、
  **同じ測定の中で指標ごとに割れる**。

## 注意

- ここは**対角**（校正 = 評価タスクの train split）で測ってある。素の文章で校正した
  系（res09 / res16）とは数字を直接並べられない。
- ARC は e と c を束ねた1タスクとして扱っているので、res16 の ARC-e / ARC-c とは
  別の集計である。
- 探索の段は無い。x を振っただけで、層別配分は出てこない。
