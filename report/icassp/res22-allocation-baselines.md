## 表の組み方（これ自体が主張になる）

行をばらばらに並べず、**配分の決め方の類型**で括る。上から読むだけで
「固定 < 規則 < 層ローカル探索 < 後続まで通す探索」が立つ。

| 群 | 行 | 参照するもの |
|---|---|---|
| **固定** | CMoE 既定（全層共通） | — |
| | 校正が選んだ一様 | 校正 |
| **規則** | EW-rule（既定 τ=0.6, α=[0.2,0.7]） | 校正 |
| | OWL 相当（既定 M=5, desc, α=[0.2,0.7]） | 校正 |
| **層ローカル探索** | LExI 相当（層ローカル誤差の独立 argmin） | 校正 |
| **順序対照** | 反転 / 並べ替え×2（提案と同じ多重集合） | — |
| **提案** | suffix KL + ビーム幅4 | 校正 |

「参照するもの」の列に意味がある。**提案だけが「評価データを見ずに」最上段に来る**
という主張が、この列だけで見える。MAPLE / Alloc-MoE のように層別感度を acc / PPL で
測る手法は、この列が「評価データ」になる（本稿では測っていない。§5 で触れるに留める）。

## 3本が何を分離するか

**順序対照** — 提案が出した配分の多重集合を保ったまま層順だけ崩す。A も平均 x も
x の度数分布も提案と厳密に同一で、違うのは「どの層にどの x が載るか」だけ。
res21 の EW-rule は平均 x=2.41 対 提案 4.60 だったので、差の一部が動作点の差で
説明できてしまっていた。**この行がその穴を塞ぐ。**

**LExI 相当** — 提案との差分が「尺度を suffix KL にした」の一点に絞られる
（どちらも層の出力誤差を測って配分を決め、LExI は層ローカル、提案は後続まで通す）。
res15 の観察2（層間依存）が予測になっている。

**OWL 相当** — 規則型を2本にする。EW-rule 1本だと負けが「EW の既定 α が N=8 に
合っていない」で説明できてしまう（res21 の注意点）。同じ写像に別の統計を載せた
2本目が同じように負ければ、原因を統計の質ではなく**方式**の側に帰せる。
