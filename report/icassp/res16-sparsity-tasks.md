**EW-rule** は ExpertWeaver (arXiv:2602.15521) の層別配分の式(4)(5)(6) だけを
現行 CMoE の分割・ルーターの上に載せたもの（既定値 τ=0.6・α∈[0.2, 0.7]、平均 x =
2.41）。分割・ルーター・校正は他の行と同一で、動かしたのは配分だけである。詳細と
有意性の検定は [res21](res21-expertweaver-baseline.md)。

**表の読み方。** `macro` は6タスク平均、`macro5` は MMLU を除く5タスク平均。
EW-rule は MMLU を測っていないので、EW-rule と比べるときは `macro5` の列を見る。
太字は列ごとの最良値（`macro` の列では EW-rule を除く10行の中での最良）。
`acc` / `gold_nll` のセルは seed 3本の平均、**PPL のセルは平均 ± 標準偏差**である
（PPL は問題単位ではなくコーパス単位の指標なので、ばらつきをそのまま出せる）。
PPL の表には EW-rule の値もある（`ew_bench*` が WikiText-2 / C4-new を測っている）。

## 注意

- **EW-rule は MMLU を測っていない。** `ew_bench*` は5タスクだけの run で、
  MMLU 側（`bench_mmlu_slimpajama*`）には EW-rule の配分が同梱されていない。
  表の MMLU / `macro` 列が「—」なのはこのため。埋めるなら EW-rule の配分ベクトル
  （report/21 結果1）で `bench_mmlu_*` を3 seed 引き直すだけで足りる。
- **EW-rule の行は uniform2 と uniform3 の間に置いてある。** 平均 x = 2.41 が
  その2点の間にあるためで、report/21 結果3（平均 x を揃えると差が消える）が
  表の上でそのまま読める並びにした。有意性はここでは示していない — 対応のある
  ブートストラップの区間は [res21](res21-expertweaver-baseline.md) にある。
- **75%（A=2）は MMLU を測っていない。** 論文で 75% を出すなら5タスクだけになる。
  数字は report/16 の該当節にある。
- MMLU は別 run（`bench_mmlu_slimpajama*`）である。校正トークンのハッシュと配分
  ベクトルは5タスク側の run と一致しており、同じ変換を別のベンチで測ったもの。
- **dense の PPL は測っていない。** 基準の表に `acc` / `gold_nll` しか無いのは
  このためで、PPL は配分どうしの比較にだけ使える。
- **`uniform0` の PPL は平均を取っても意味が無い。** x=0（全層 routing のみ）は
  seed によって崩れ方が違い、25% で 86.10 ± 109.10、50% で 5442.10 ± 5233.88 と
  標準偏差が平均を超える。壊れていることの記述であって、大小の比較には使えない。
- PPL の EW-rule 行は `ew_bench{,_a4}_seed{0,1,2}` から取った。同 run に同梱された
  対照（A=6 は `uniform3`、A=4 は `uniform2`）の PPL は `exp0{6,7}_seeds` 側の
  同じ配分と完全一致しており、run をまたいで同じ表に並べてよいことを確認してある。
