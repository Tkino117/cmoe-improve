## 何を測ったものか

採点オラクルは両方とも `suffix_kl`（dense モデルとの出力分布の KL）で、評価回数も
同じ（層数 × 候補数）。違うのは、層を決めたあと次の層へ渡す状態だけである。

| 探索 | 次の層へ渡す状態 | 層 ℓ の候補を測るモデル |
|---|---|---|
| **幅1**（`--search beam --width 1`） | 決めた x で変換した状態 | 層 0..ℓ−1 を決めた x で変換、層 ℓ を候補で変換、層 ℓ+1.. は dense |
| **独立**（`--search independent`、今回追加） | dense のままの状態 | 層 ℓ だけを候補で変換、ほかの層は dense |

独立の層ごとのスコアは単独変換のモデルの値なので、表の `score` は決まった配分を
頭から測り直した値である（`search.json` の `score` と `recheck.score` は一致）。

PPL は同じ実行の中で4構成を測った: `uniform{A/2}`（CMoE の既定）・幅1・幅2・独立。
幅2 の配分は [report/27](27_two-models-5seeds.md) の別マシンで探したもの
（`result_logs/exp27_imported/`）で、測定だけをここで引き直した。

| | |
|---|---|
| モデル / 層数 | `meta-llama/Llama-2-7b-hf` / 32 |
| N / A | 8 / 6（スパース率25%）・8 / 4（50%） |
| 校正 | slimpajama 16本×2048、seed 0 / 1 / 2 / 3 / 4 |
| 採点オラクル | `suffix_kl` |
| 分割 / ルーター | 現行 CMoE（k_act 10 / bias_speed 0.001）。固定 Top-K |
| 評価 | PPL のみ。WikiText-2 test / C4-new validation。ベンチは測っていない |
| 再抽出 | 10,000回 / seed 20260813。seed を層とした評価塊の対応再抽出 |
| 環境 | RTX PRO 5000 Blackwell 1枚 |
| コード | 0ef9fd7 + 未コミットの作業木（`independent` の追加） |

**既存の探索を再利用したもの。** 25% の幅1 は `result_logs/slimpajama_w1_n16_seed<N>`
（同じ機械・同じ引数・同じ校正トークンのハッシュ）を読んだ。50% の幅1 と、独立の
全10本は今回探した。

所要は 25% が1 seed 約35分（独立の探索＋PPL 4構成）、50% が約50分（独立と幅1 の
探索＋PPL 4構成）、10本で計 7.1 時間（09:41〜16:44）。
