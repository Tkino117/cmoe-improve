# 07 混合コーパスで校正した配分を、seed 3本で測る

2026-08-24 / 実験 `experiments/06_slimpajama_seeds/` /

## 目的

[report/06](06_slimpajama-alloc-benchmark.md) は slimpajama 校正の**seed 1本**で、
探索配分が PPL でどの一様配分よりも良いことを見た。同じ格子を seed 0 / 1 / 2 で
測る。seed 0 は report/05・06 の測定をそのまま使い、seed 1・2 を新しく回した。

対照の取り方も変えた。report/04・06 は「評価指標を見てから一様7本の最良」を
対照に置いていたが、探索は校正データだけを見て配分を1本選ぶので、対照の側にだけ
選び直しのぶんが乗る。ここでは**一様7本を探索と同じ `suffix_kl` で採点し**、
その最良を第3の対照に加えた（`cmoe score`）。

## 結果

3 seed × 3幅の9本すべてで、勝った配分を頭から測り直した差は **0.000e+00**、
この機械の非決定性の床も 0.000e+00 だった。コストと評価回数は幅ごとに一定
（幅2: 7,168 `layer_forwards` / 441回、幅3: 10,640 / 658、幅4: 14,112 / 875）。
一様1本の採点はどれも 528 `layer_forwards`。

## 効き目の限界

ブートストラップが再抽出するのは評価塊と問題であって、**seed ごとに配分ベクトルが
変わるぶんの分散は3本では測れない**。そこを補うのが per-seed の符号一致（上の表の
括弧）である。ベンチの効果量は `acc` で 0.005 程度、区間の半幅が ±0.005 前後で、
3 seed でもこの桁が限界である。
