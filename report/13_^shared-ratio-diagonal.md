# 13 対角の上で shared/routed 配分を振る（S3A3E8〜S6A0E8）

2026-08-29 / 実験 `experiments/12_shared_ratio_diagonal/` /
出力 `result_logs/bench_shared_{piqa,winogrande,arc,hellaswag}_{uniform3,uniform5,uniform6}_seed{0,1,2}` /
`S4A2E8` の行は [report/12](12_calib-task-matrix.md) の対角
（`result_logs/bench_calibtask_*_seed{0,1,2}`）をそのまま読む

## 問い

配分 x は「その層で常時使う shared expert の数」で、routed の Top-K は `A − x`
である。**x = A（= 6）のとき Top-K = 0 になり、ルーティングが消えて、残った
A/N のニューロンを常時使う静的マスクと一致する**（枝刈りの退化ケース）。

report/12 は校正 × 評価の対角が効くことを示したが、配分は `uniform4`
（= S4A2E8）1点に固定していた。ここは**対角の上だけ**で x を 3〜6 に振り、
最適点が端（x=6）にあるか内側にあるかを測る。

## 設定

| | |
|---|---|
| モデル / 層数 | `meta-llama/Llama-2-7b-hf` / 32 |
| N（expert 数）/ A（1トークンあたり） | 8 / 6（スパース率25%） |
| 配分 | `uniform3` / `uniform4` / `uniform5` / `uniform6`（= S3A3E8 / S4A2E8 / S5A1E8 / S6A0E8）。**x をどう変えても1トークンあたりに走る expert 数は 6 で同じ** |
| 校正 | 対角のみ。評価タスクの train split から 8本 × 2048トークン（= 16,384トークン）、seed 0 / 1 / 2 |
| ルーター / 分割 | 現行 CMoE（k_act 10 / bias_speed 0.001）。x=6 は Top-K=0 なのでルーターは出力に効かない |
| ベンチ | PIQA / WinoGrande / ARC / HellaSwag、0-shot・全件、batch 32。ARC は report/12 と同じく ARC-e + ARC-c を束ねた1タスク |
| PPL | wikitext2 / c4-new |
| ブートストラップ | 10,000回 / seed 20260813 |
| dense の基準 | report/04 のものを取り込み（`bench_h4/wikitext2_seed0/bench/dense.json`） |
| コード | `5a0efb5` + `experiments/12_shared_ratio_diagonal/`（未コミット） |
| 所要 | 新規36構成、1構成あたり平均 9.1分（計 5.5時間）。失敗0 |

**校正セット・動作点・ルーター・評価・dense の基準は report/12 と同じ**で、
動かしたのは配分だけである。行（校正タスク）は対角の4本に絞った。

問題数は PIQA 1,838 / WinoGrande 1,267 / ARC 3,548 / HellaSwag 10,042。

## 結果

### `acc`（3 seed 平均）

どのマスも「そのタスクの train split で校正し、そのタスクで測った」ものである。
太字は列の最良。

| 配分 | Top-K | PIQA | Wino | ARC | HSwag | macro |
|---|---|---|---|---|---|---|
| `S3A3E8` | 3 | 0.7668 | 0.6651 | 0.6138 | 0.5330 | 0.6446 |
| `S4A2E8` | 2 | **0.7713** | 0.6575 | 0.6160 | 0.5390 | 0.6459 |
| `S5A1E8` | 1 | 0.7700 | 0.6717 | **0.6297** | 0.5389 | **0.6526** |
| `S6A0E8` | 0 | 0.7673 | **0.6769** | 0.6195 | **0.5403** | 0.6510 |
| dense（変換なし） | — | 0.7802 | 0.6953 | 0.6485 | 0.5708 | 0.6737 |

列の最良は PIQA が x=4、ARC が x=5、Wino と HSwag が x=6。macro は x=5。

### `S6A0E8`（Top-K=0）との差

列ごとに、その列の問題を対応づけた **seed を層とするペア付き再抽出**（10,000回）。
符号は「大きいほど良い」向きに揃えてあり、**正なら x < 6 の側が良い**。
`*` は 95% 区間が0をまたがない。

**`acc`**
