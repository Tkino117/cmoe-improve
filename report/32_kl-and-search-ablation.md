## 何を測ったものか

[report/31](31_calibration-amount.md) は校正を n=64 に増やすと配分探索の効きが
開くことを示した。その n=64 で、**配分の決め方を4段に分けて測った**ものである。

| 段 | 構成 | 評価回数 | 前の段との違い |
|---|---|--:|---|
| 0 | `uniform3` | 0 | — |
| 1 | `independent` | 224 | 出力 KL を目的関数にする（層ごとに閉じた決定） |
| 2 | 幅1（beam B=1） | 224 | 次の層へ**変換済みの状態**を渡す。段1 と**同一コスト** |
| 3 | 幅2 / 幅3 | 441 / 658 | 候補を B 本残して進む |

段1 と段2 は**採点オラクル（`suffix_kl`）も評価回数も同じ 224 回**で、違うのは
次の層へ渡す状態だけである（段1 は dense のまま、段2 は決めた x で変換した状態）。

[report/29](29_independent-kl.md) が n=16・seed 0〜4 で測った対照を、n=64・
seed 5〜9 に移した形である。**seed も校正量も違うので、report/29 の数字とは
混ぜていない。**

### Page のトレンド検定（順序つきの対立仮説、厳密 p）

帰無分布は各 seed の順位付けが一様な置換という仮定の全列挙による
（3水準で 6⁵ = 7,776 通り、4水準で 24⁵ = 7,962,624 通り）。片側である。

| 水準 | 仮説の順序 | 順位和 | L | WT2 の p | C4 の p |
|---|---|---|--:|--:|--:|
| 幅1 / 幅2 / 幅3 | 幅3 < 幅2 < 幅1 | WT2 13/9/8、C4 13/10/7 | 65 / 66 | 0.0795 | 0.0394 |
| `independent` / 幅1 / 幅2 / 幅3 | 幅3 < 幅2 < 幅1 < `independent` | WT2 15/15/11/9、C4 18/15/10/7 | 136 / 144 | 0.0524 | **0.0010** |

順序を使わない検定では、3水準の Friedman が WT2 p=0.247・C4 p=0.165、
二元配置の F(2,8) が WT2 p=0.106・C4 p=0.190 だった。
