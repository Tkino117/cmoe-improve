# 27 2モデル × 2スパース率 × 5 seed の配分探索

2026-09-11 / 実装 `experiments/25_model_seeds/`（`run.py` / `sweep.py` /
`summarize.py`）/ 出力 `result_logs/{slimpajama*,score_uniform_*,bench_slimpajama*}`
（測定は RTX 6000 Ada 4枚の別マシン、Docker 内。手順は
[docs/05](../docs/05_running-the-sweep.md)）

これまで seed 3本・Llama-2-7b 1モデルだった配分探索の測定を、**2モデル × 5 seed**
に広げたもの。20ジョブ（2モデル × 2動作点 × 5 seed）を4枚の GPU に1ジョブ1枚で
配って回した。

## 設定

| | |
|---|---|
| モデル / 層数 | `meta-llama/Llama-2-7b-hf` / 32、`mistralai/Mistral-7B-v0.1` / 32 |
| N / A | 8 / 6（スパース率25%）・8 / 4（50%） |
| 校正 | slimpajama 16本×2048、**seed 0 / 1 / 2 / 3 / 4**。探索も seed ごとに引き直す |
| 採点オラクル / 探索 | `suffix_kl` / beam 幅2・3・4 |
| 分割 / ルーター | 現行 CMoE（k_act 10 / bias_speed 0.001）。固定 Top-K |
| 評価 | 0-shot・全件。PIQA / WinoGrande / ARC-e / ARC-c / HellaSwag。PPL は WikiText-2 test / C4-new validation |
| dense の基準 | モデルごとに1回、同じマシンで測ったもの（`result_logs/exp25_check/`） |

**測定環境を1台に揃えてある。** 効果量が `acc` で 0.005〜0.012 と小さく、GPU が
違うと浮動小数の積み方が変わって同じ桁の差が出かねないため、Llama の seed 0〜2 も
旧マシンの結果を使わず引き直した。dense の基準も同じ理由で測り直している。

**`提案 幅W`** は本手法（`suffix_kl` + ビーム幅W）。**`uniform{x}`** は全層で
shared expert を x 個に固定した対照で、x を変えても1トークンあたりに走る expert
数は A で同じである。セルは **seed 5本の平均 ± 標準偏差**。

**MMLU はこの表に入っていない。** A=6 は5 seed 揃っているが A=4 が未測定で、
揃ってから別に出す。EW-rule と report/22 の対照5行も、モデル引数化が済んでいない
ため入っていない。
