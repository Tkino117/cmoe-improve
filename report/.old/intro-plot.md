# イントロのプロット（配分探索 + 可変 Top-K 版）

2026-09-02。各段落の末尾の［］は根拠の在りか。

## 1. 背景

- LLM の推論コストは FFN が大半を占める。MoE の条件付き計算はそれを削るが、既存 MoE は大規模事前学習が前提。
- 近年、学習済み dense モデルを再学習なしで MoE 化する training-free 変換が出てきた（CMoE、ExpertWeaver）。FFN のニューロンを shared expert と routed expert に分け、トークンあたり A 個だけ起動する。勾配計算がなく、少量の校正データで数分で終わる。

## 2. 課題: 予算の「配り方」が手で固定されている

- これらの手法は「トークンあたり A 個」という予算を守るために、2つの個数を定数で固定している。
  - 層ごとの shared 数 x。CMoE は全層で同じ値。
  - トークンごとの routed 数 K。どのトークンにも必ず K 個（Top-K）。
- どちらも性能を左右するのに、根拠は経験則である。ExpertWeaver は x を層ごとに変えたが、それを決めるしきい値と上下限は手で置いた値のまま。K をトークンごとに変えた研究（D2DMoE、DynaMoE、Top-P routing）は、いずれもルーターの学習か fine-tuning を要し、training-free の設定では前例がない。
- 共通の原因は、校正データを「統計量の算出」にしか使っていないこと。構成した結果を評価して決定に戻す経路がないため、残る設計判断は定数で埋めるしかない。
  ［CMoE §4.2、ExpertWeaver §3.2、D2DMoE §dynamic-k、DynaMoE abstract］

## 3. 観察: 2つの個数は、どちらも「測って決める」しかない

層の側（x）:
- 最良の一様 x は評価データごとに違い、普遍的な定数はない。
- 層ごとに独立に最良を選ぶ貪欲法は一様配分に勝てない。一方、探索で保持する候補を増やすほど目的関数は改善する。ある層の配分の良し悪しが他の層に依存しており、層ローカルの代理指標では捉えられない。
- したがって、構成した結果そのもの（dense の出力分布との KL）を見て決めるしかない。
  ［report/02・03・15。既存原稿 §3 のまま］

トークンの側（K）:
- CMoE 自身の目的関数は「非活性 expert の活性質量 Σ‖h‖₁ を最小化する」である。この目的を「平均 K 個」という予算制約の下で厳密に解くと、解は Top-K ではなく score の大域しきい値になる。Top-K は、この目的を各トークンに等分するという追加の制約を勝手に置いている。
- 配備できないオラクルで測ると、「どの K 個か」を完璧にして得られる改善より、「何個か」を解放して得られる改善の方が 2 倍大きい。
- 効くのは score の絶対値である。トークンごとに正規化する D2DMoE 型の相対しきい値は固定 K を超えず、softmax はこの情報をちょうど捨てる。
  ［CMoE 式6、report/19 結果1、report/20 §方式8-2］

## 4. 提案: 固定した予算を、層とトークンの両方向に校正データから配る

- トークンあたり A 個という予算はそのまま守り、その配り方だけを校正データから決める。
  - 層をまたいで: 層別の x を、dense との KL を目的に beam search で探す。層間の相互作用を捉えるため、候補を幅 B 本保持したまま層を進める。
  - トークンをまたいで: routed の個数を Top-K から解放し、softmax 前の score をしきい値 τ と比べて選ぶ。τ は校正データ上で平均個数がちょうど K になる分位点として一意に決まる。
- 新たに手で調整するしきい値を導入しない。B は計算量と品質の単調なトレードオフで、τ は予算から決まる。
- 推論時の計算量は増えない。beam search は変換時に一度だけ、しきい値は Top-K と同じ score の読み方を変えるだけで積和は増えない。実測の起動数は予算以下に収まる。
- 重みの値は変えないので、fine-tuning と競合せず、その前段として使える。

## 5. 貢献

- training-free 変換の中で手で固定されていた2つの個数（層ごとの shared 数、トークンごとの routed 数）を、固定予算の下で校正データから決める設計変数として定式化する。
- 層方向には beam search、トークン方向には予算から決まるしきい値という、調整パラメータを新たに持ち込まない2つの手続きを提案する。
- Llama-2 7B で、追加の推論コストなしに親モデルへの忠実度と選択問題の指標が一貫して改善することを示す。
