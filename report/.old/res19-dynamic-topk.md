## 予算を守っているかの実測

`dynamic_cmoe` は予算を**平均でしか**守らないので、実際に走った routed expert 数を
評価データの上で測る必要がある。固定 Top-K の2方式はどの評価データでも 3.000。

| seed | wikitext2 | c4-new | bench | bench の分布 (k=0..5) |
|---|--:|--:|--:|---|
| 0 | 3.0057 | 2.9596 | 2.9003 | 0.040 / 0.081 / 0.224 / 0.328 / 0.249 / 0.078 |
| 1 | 3.0216 | 2.9955 | 2.9195 | 0.038 / 0.083 / 0.218 / 0.325 / 0.254 / 0.082 |
| 2 | 3.0112 | 2.9802 | 2.9184 | 0.037 / 0.082 / 0.220 / 0.328 / 0.253 / 0.080 |

**ベンチの上で 2.90〜2.92 しか走っていない** — routed expert の本数で約3%、
shared を含む積和の比では約1.5% 少ない計算で、上の改善が出ている。
トークンの約4% は routed を1つも使わず、約8% が5つ全部を使う。
