## 1. はじめに

大規模言語モデルの推論コストは、その実用化における主要な制約となっている。この制約を
緩和する有力な方向の一つが、Mixture-of-Experts (MoE) による条件付き計算である。しかし
MoE の恩恵を受けるには通常ゼロからの事前学習を要し、学習済みの dense モデルを MoE へ
変換する手法もまた、品質の回復に大規模な継続事前学習や router の学習を必要としてきた
[MoEfication, LLaMA-MoE]。近年、勾配計算を一切伴わずにこの変換を行う training-free な
アプローチが提案されている [CMoE, EW]。これらは各層の FFN のニューロンを、全トークンで
常時起動する shared expert と、ルーターが選択的に起動する routed expert とに分割し、
1 トークンあたりに起動する expert の個数を一定に制限する。総パラメータ数は dense モデルと
同一に保たれ、削減されるのは 1 トークンあたりの活性パラメータ数である。分割もルーターも
校正データ上の活性化統計量から解析的に構成されるため、変換は少量のデータと数分の計算で
完了する。

この起動予算は、1 トークンあたりの合計個数に対する制約にすぎず、それを層ごとにどう配る
かは指定しない。各層で shared にいくつ割くかを決めれば、その層で routed から起動できる
個数は予算の残りとして自動的に決まる。したがって、層ごとの shared と routed の内訳が、
予算を守りながら選べる構成上の自由度である。shared を少なく取ればその層は入力に応じた
ルーティングに強く依存し、多く取れば常時起動の比率が上がる。層によって担う役割が異なる
以上、この内訳は層ごとに異なってよいはずだが、既存手法はこれを経験的な定数で埋めている。
CMoE は全層で同一の値を用い
[CMoE]、層ごとの配分を導入した ExpertWeaver でも、配分を決める指標のしきい値と上下限は
経験的に固定されており、結果はその設定に依存する [EW]。踏み込めていないのは、決め方が
無いからである。これらの手法において校正データが使われるのは、どのニューロンを shared に
するか、ルーターの重みをどう構成するかという、モデルを組み立てる段階の統計量を得る
ためだけである。組み上がったモデルの良し悪しを測り、それを組み立て方に反映させる経路は
存在しない。手続きが一方向であるため、活性化統計量から直接は決まらない変数——配分は
その代表である——は、定数か人手の調整で埋めるほかない。

自然な対処は、より良い代理指標を設計することであろう。層ごとの感度や出力誤差のような量を
測り、それに応じて予算を割り当てればよい。しかし我々の観察は、この方向が行き止まりで
あることを示す。第一に、層一律の配分に普遍的に最適な値は存在しない。起動予算を固定した
まま一律の配分だけを動かすと、最良の値は評価データによって変わり、さらに perplexity が
選ぶ値と選択問題の正答率が選ぶ値も一致しない。単一の定数をより良く選び直すことでは
解決しない。第二に、より本質的な問題として、層ごとに独立に最良の配分を選ぶ素朴な貪欲法は、
一様配分に対して明確な改善をもたらさない。一方、確定を保留して複数の配分候補を保持した
まま層を進めると、校正データ上の目的関数は保持する候補数に応じて改善する。同様に、ある層
の配分を確定する前に次の層まで展開すると、その層だけを見たときの最善はしばしば覆る。
これは、ある層の配分が生む誤差を後続の層が吸収するのか増幅するのかが、その層だけを見ても
決まらないことを意味する。層間にこの相互作用がある限り、層をローカルに評価する指標が
どれほど精緻であっても、配分は決められない。

必要なのは、より良い代理指標ではなく、構成した結果を測って決定に戻す経路である。そして
training-free な変換の設定では、この経路は原理的に安価である。校正データは既に手元に
あり、変換が近似すべき対象は元の dense モデルそのものであるから、構成したモデルと dense
モデルの出力分布の乖離を、追加の教師なしにその場で測れる。既存手法はこの測定を、変換の
後段の評価としては行っても、変換の決定には用いてこなかった。本論文では、層別配分を、
起動予算を固定した制約の下でこの乖離を最小化する探索問題として定式化する。目的関数が
モデル全体の出力である以上、層間の相互作用は代理指標で近似する必要がなく、目的関数の中に
初めから含まれている。ただし配分の組合せは層数に対して指数的に増えるうえ、層ごとに確定
させる貪欲法ではその相互作用を取りこぼす。そこで、複数の配分候補を幅 B 本保持したまま層を
進める beam search を用いる。B = 1 が貪欲法に対応し、B を大きくするほど全探索に近づく。
この定式化は、既存
手法の問題を三つの意味で解消する。第一に、性能を左右する経験的なしきい値を新たに導入
しない。唯一の調整対象は探索の幅 B であり、これは当たり外れのあるハイパーパラメータでは
なく、計算量と得られる配分の質との単調なトレードオフである。第二に、探索は変換時に一度
だけ実行され、出力される配分は既存手法と同じ形式の expert 構成であるから、推論時の計算量
もパラメータ数も増加しない。第三に、重みの値を一切変更せず構成のみを決定するため、
fine-tuning と競合せず、その前段として併用できる。

本論文の貢献は以下の通りである。

- training-free な MoE 変換において経験的な定数で埋められてきた層別配分が、校正データ上で
  直接最適化できる設計変数であることを示す。層一律の配分に普遍的な最適値が存在しないこと、
  および層間の相互作用のために層ローカルな指標では配分を決められないことを、実測によって
  示す。
- 起動予算を固定した制約の下で dense モデルとの出力分布の乖離を最小化する配分探索を
  定式化し、層間の相互作用を扱う beam search を提案する。新たな経験的しきい値を導入せず、
  推論時の計算量を増加させない。
- Llama-2 7B・三段階のスパース率において perplexity が一貫して改善し、スパース率の高い
  領域では親モデルへの忠実度を測る指標が有意に改善することを示す。

## 2. 手法

### 2.1 準備: training-free な dense-to-MoE 変換

CMoE は、学習済み dense モデルの FFN 層を追加学習なしに MoE 化する。各層の FFN について、
校正データに対する各ニューロンの活性化頻度を測り、頻度の高い上位のニューロンを shared
expert として全トークンで常時起動させる。残りのニューロンは活性化パターンが似たものどうし
でクラスタリングし、routed expert に分割する。ルーターは各 routed expert の代表ニューロン
に対応する重み列だけを残した縮約ゲートとして解析的に構成され、推論時にはそのスコア上位
Top-K の routed expert だけが追加で起動される。

総パラメータ数は dense モデルと同一のまま保たれ、1 トークンあたりに計算される expert 数、
すなわち層 ℓ の shared 数 x_ℓ と routed の起動数 K_ℓ の和は、全層で共通の予算 A に固定
される。

  A = x_ℓ + K_ℓ   (ℓ = 1, …, L)

配分 x_ℓ ∈ {0, …, A} は層ごとに独立に選べるが、CMoE は全層で同一の値 x_ℓ = x を用いる。
なお x_ℓ = A のとき K_ℓ = 0 となり、その層ではルーティングが消えて A/N のニューロンを
常時使う静的マスクに退化する。すなわち配分の探索空間は、その端に静的な枝刈りを含む。

### 2.2 配分探索の定式化

配分の良さは、変換後のモデルの出力分布が dense モデルからどれだけ乖離するかで測るのが
自然である。層ごとの出力誤差のような層ローカルな指標は、その層で生じた誤差を後続の層が
吸収するのか増幅するのかを言えない。1 節で述べたように、層間にはこの伝播を無視できない
相互作用がある。

そこで、層 1 から ℓ までを配分 (x_1, …, x_ℓ) で変換した MoE とし、残りの層 ℓ+1 以降は
dense のまま実行して得られる出力分布を P_pre、完全な dense モデルの出力分布を P_dense と
して、校正データ上のトークン平均 KL ダイバージェンス

  score(x_1, …, x_ℓ) = (1/T) Σ_t KL( P_dense(t) ‖ P_pre(t) )

を接頭辞のスコアとする。残りの層を dense で置き換える仮定を含むため、これは ℓ < L では
見積もりに過ぎず、ℓ = L でだけ実際に配備されるモデルの KL と一致する。目的は、制約
x_ℓ + K_ℓ = A（∀ℓ）のもとでこの最終スコアを最小化する配分 x* を求めることである。

### 2.3 beam search による探索

上記の目的関数を層 1 から順に評価しながら、良い接頭辞を幅 B 本だけ残して層を進める
beam search により x* を近似する。層 ℓ では、保持している B 本の接頭辞それぞれについて
次候補 x_{ℓ+1} ∈ {0, …, A} をすべて試して子を作り、子をスコアで並べ替えたのち上位 B 本
だけを残して層 ℓ+1 に進む。この操作を L 層分繰り返した末に残る最良の 1 本を最終的な配分
として出力する。ある層で捨てられた接頭辞は、以降どれだけ良い枝を持っていても復元されない。

B = 1 のときは、各層でその場のスコアが最良の 1 本だけを残す貪欲な歩き方に退化する。
1 節で述べた貪欲法の失敗は、この幅の下限に相当する。

子 1 つの評価は、その子から残りの層を dense として走らせる forward を要するため、層 ℓ の
子 1 つあたりのコストは L − ℓ に比例する。したがって全体のコストは幅 B と候補数 A+1 に
対して線形、層数 L に対しては L² のオーダーで増える。

### 2.4 性質

この探索は、性能を左右する新たな経験的しきい値を一切導入しない。唯一の調整対象は探索の
予算 B であり、計算量と発見される配分の質との単調なトレードオフとして扱える。探索は
モデル変換時に一度だけ実行され、得られる配分自体は CMoE と同じ形式の expert 構成である
ため、推論時の計算量やパラメータ数は変化しない。また、この手続きは既存の重みの値を
一切変更せず構成のみを決定するため、fine-tuning による後段の調整とは独立に適用でき、
両者は競合しない。

## 3. 実験

### 3.1 設定

| | |
|---|---|
| モデル / 層数 | `meta-llama/Llama-2-7b-hf` / L = 32 |
| expert 数 N | 8（固定） |
| 起動予算 A | 6（スパース率 25%）/ 4（50%）/ 2（75%） |
| 校正 | SlimPajama、n = 16 × 2048 トークン、seed 0 / 1 / 2 |
| 目的関数 | 校正データ上で dense 出力分布と取る KL（2.2 節） |
| 探索 | beam 幅 B = 2 / 3 / 4 |
| ルーター / 分割 | CMoE（k_act 10 / bias_speed 0.001）、固定 Top-K |
| 評価 | PIQA / WinoGrande / ARC-e / ARC-c / HellaSwag（0-shot・全件）、MMLU（test 14,042 問）、perplexity（WikiText-2 / C4-new） |
| 統計 | 問題単位・(seed × タスク) を層とするブートストラップ 95% 区間、10,000 回 |

スパース率は A/N で定義し、三段階は A 以外の設定が同一である。

対照は、一様配分 x = 0, …, A を探索と同じ目的関数・同じ校正データで採点したときの最良と
する。探索も対照も「校正だけを見て選んだ 1 本」になるため、これが対等な比較である。実際
に選ばれたのは 25% で uniform6（seed 0, 2）と uniform5（seed 1）、50% では 3 seed とも
uniform4 だった。50% の uniform4 は x = A、すなわち全層で routing を持たない静的マスク
である。［res09］

### 3.2 層一律の配分に最適な定数は存在しない

A = 6 に固定して層一律の x のみを 3〜6 に振り、評価タスクごとの最良を見る（校正は各評価
タスクの train split、3 seed 平均）。

| 配分 | Top-K | PIQA | WinoGrande | ARC | HellaSwag | macro |
|---|--:|--:|--:|--:|--:|--:|
| x = 3 | 3 | 0.7668 | 0.6651 | 0.6138 | 0.5330 | 0.6446 |
| x = 4 | 2 | **0.7713** | 0.6575 | 0.6160 | 0.5390 | 0.6459 |
| x = 5 | 1 | 0.7700 | 0.6717 | **0.6297** | 0.5389 | **0.6526** |
| x = 6 | 0 | 0.7673 | **0.6769** | 0.6195 | **0.5403** | 0.6510 |
| dense | — | 0.7802 | 0.6953 | 0.6485 | 0.5708 | 0.6737 |

最良の x は列ごとに 4 / 6 / 5 / 6 と割れ、macro の最良は端（x = 6、ルーティングなし）では
なく内側の x = 5 にある。gold_nll でも最良は 5 / 6 / 5 / 6 と同様に割れる。一方 perplexity
は WikiText-2・C4-new とも x = 3〜4 が最良で、正答率が選ぶ x とは逆側にある。また、校正
データを引き直すだけでも目的関数が選ぶ一様配分は変わる（3 seed で uniform6 / uniform5 /
uniform6）。［res13］

### 3.3 層間の相互作用

保持する候補を増やすほど目的関数が改善する。下表は校正データ上の KL（小さいほど良い。
値は同じ校正トークン上でのみ比較可能）。

| seed | 最良の一様 | B = 2 | B = 3 | B = 4 |
|---|--:|--:|--:|--:|
| 0 | 0.19214 | 0.18364 | 0.18185 | **0.18059** |
| 1 | 0.20360 | 0.19969 | 0.19468 | **0.19372** |
| 2 | 0.18387 | 0.17496 | 0.17496 | **0.17276** |

9 本すべてがその seed の最良の一様を下回り、B について 3 seed とも単調非増加である。探索
コストは B に対して線形（7,168 / 10,640 / 14,112 層 forward）であり、B は品質と計算量の
単調なトレードオフとして機能している。［res15 (a)］

候補を 1 本に絞る、すなわち層ごとに独立に確定する貪欲法は最も悪い。別の校正データ上で
B = 1, 2, 3 を比較すると、B = 1 は目的関数で 3 seed すべて最下位であり、下流の正答率でも
3 本の中で最下位である（一様配分との差が B = 1 で −0.0033、B = 2 で −0.0022、B = 3 で
−0.0025）。［res15 (b)］

確定を 1 層遅らせると、刈る枝が変わる。幅を B = 2 に据え置き、子ごとに次層の候補をすべて
展開してその最良を子の順位に用いると、「その層だけを見た最善」が覆った分岐は 3 seed で
63 分岐中 21 / 17 / 18 だった。出力される配分も 32 層中 19〜23 層で変わり、目的関数は
3 seed 中 2 seed で改善する。下流でも gold_nll −0.031258、margin +0.042150、ref_kl
−0.009322、WikiText-2 の NLL −0.002306 と改善する（いずれも 95% 区間が 0 をまたがない）。
層をローカルに評価する指標では、この覆りは原理的に予測できない。

ただし先読みは計算量が 7.57 倍（54,257 対 7,168 層 forward）に対し 3 seed 中 2 seed の
改善であり、同じ相互作用を幅で捉えるほうが費用対効果が高い。提案手法が深さではなく幅を
採るのはこのためである。［res15 (c)］

### 3.6 探索が出した配分

探索は層をまたいで大きく異なる配分を出す（seed 0、B = 4）。

```
25% (A=6): 4,6,6,5,6,6,5,6,4,2,4,2,3,3,4,4,5,6,5,4,6,4,5,5,3,4,6,6,4,2,2,4
50% (A=4): 2,4,4,4,4,4,4,4,4,3,0,3,1,2,4,4,4,4,4,4,4,4,4,4,4,4,3,4,3,2,4,2
```

25% では平均 x = 4.41（A の 73.4%）で 32 層中 23 層がルーティングを使う。50% では平均
x = 3.41（85.2%）で、ルーティングを使うのは 10 層のみである。ここで注目すべきは 50% で
ある。一様配分の枠内では、校正データが選ぶ最良は uniform4、すなわち全層でルーティングを
捨てた静的マスクだった。層別に配分できるようにすると、探索は 10 層にだけルーティングを
残し、その静的マスクを有意に上回る（3.4 節）。層一律という制約が、この設定ではルーティング
の価値そのものを覆い隠していたことになる。［res09］

---

## 4. 結論

training-free な dense-to-MoE 変換において経験的な定数で埋められてきた層別配分を、起動
予算を保ったまま校正データ上の目的を直接最適化する探索問題として定式化した。層一律の
配分には評価データをまたいで最適な定数が存在せず、かつ層間に相互作用があるため層ローカル
な代理指標では決められないことを実測で示し、複数の配分候補を保持したまま層を進める
beam search を提案した。Llama-2 7B において、新たな経験的しきい値を導入せず、推論時の
計算量を増やすことなく、perplexity が三段階のスパース率で一貫して改善し、スパース率 50%
では親モデルへの忠実度を測るすべての指標で有意に改善した。
