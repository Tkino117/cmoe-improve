# 03 層ごとに探した配分は、一様配分に勝つか（seed 3本）

2026-08-20 / 実験 `experiments/04_h1h3_pilot/` / 出力 `result_logs/h1h3_pilot{,_seed1,_seed2}`、
まとめ `result_logs/h1h3_pilot_seeds/`

## 目的

[report/02](02_alloc-search-vs-uniform.md) と同じ実験を **seed 0 / 1 / 2 の3本**で回し、
seed 間のばらつき込みで見る。seed 0 の測定は report/02 のものをそのまま使っている。

## 設定

report/02 と同一。振ったのは校正に引く8本を選ぶ seed だけ。

| | |
|---|---|
| モデル / 層数 | `meta-llama/Llama-2-7b-hf` / 32 |
| N（expert 数）/ A（1トークンあたり） | 8 / 6（全構成で同一） |
| 校正 | 8本 × 2048トークン、seed 0 / 1 / 2 |
| 探索 | beam（幅 2 / 3 / 4）× オラクル `suffix_kl` |
| ルーター / 分割 | 現行 CMoE（k_act 10 / bias_speed 0.001） |
| 環境 | RTX PRO 5000 Blackwell、Python 3.11.14 / PyTorch 2.8.0+cu128 / transformers 4.47.1 |
| コード | seed 0 は `4961c47` + 当時のスクリプト、seed 1・2 は `92432c5`（`--seed` 対応。測定内容は同一） |
| 所要 | 237.8 / 238.0 / 240.3 分 |

配分を探す文章①とモデルを組む文章②は seed ごとに**同じ8本に揃えた**。

| 用途 | セット | seed 0 | seed 1 | seed 2 |
|---|---|---|---|---|
| 校正（H1・H2） | WikiText-2 train | `65a051f78ade` | `8f6d5fabf4c7` | `e860866a5448` |
| 校正（H3） | C4 train | `b69ba8e36390` | `63abc37a946f` | `3afc1f144bd5` |

評価文章はどの seed でも同一（WikiText-2 test 全体 341,469トークン `add5c2673056` /
C4 validation 先頭1100文書 524,288トークン `bbd0f3f758ec`）。

```bash
uv run python experiments/04_h1h3_pilot/run.py --seed 1
uv run python experiments/04_h1h3_pilot/summarize_seeds.py --seeds 0,1,2
```

wikitext2・幅2 の探索は report/01 の seed 0〜2 を再利用した（配分ベクトルだけを
引き継ぎ、モデルは組み直して測り直している）。

## 結果

組み方も変わるので、左右2組は直接は比べられない。

この標準偏差には、その seed が引いた8本の当たり外れが**全構成に共通で**乗っている。
配分どうしの比較にはその成分が要らないので、同じ seed の中で引いてから3本で平均した
表も出す。

### 最良の一様配分との差

seed ごとに最良の一様配分を選び、同じ seed の中で引いてから3本で平均した。負なら
「その seed のどの一様配分よりも良い」。括弧は3本のうち負だった本数。

| 配分 | 校正 wikitext2 → wt2 | → c4-new | 校正 c4 → wt2 | → c4-new |
|---|---|---|---|---|
| beam 幅2 | -0.016772 ± 0.022560（2/3） | +0.033858 ± 0.034944（0/3） | +0.079864 ± 0.112338（1/3） | -0.022059 ± 0.027752（**3/3**） |
| beam 幅3 | -0.019969 ± 0.024229（2/3） | -0.005282 ± 0.031952（2/3） | +0.012605 ± 0.082736（2/3） | -0.057570 ± 0.030730（**3/3**） |
| beam 幅4 | -0.032621 ± 0.005296（**3/3**） | -0.014394 ± 0.052591（1/3） | +0.158141 ± 0.200978（0/3） | -0.046714 ± 0.012339（**3/3**） |

最良だった一様配分は seed で変わる。

| 校正 / 評価 | seed 0 | seed 1 | seed 2 |
|---|---|---|---|
| wikitext2 / wt2 | uniform4 | uniform5 | uniform4 |
| wikitext2 / c4-new | uniform4 | uniform3 | uniform3 |
| c4 / wt2 | uniform4 | uniform4 | uniform4 |
| c4 / c4-new | uniform4 | uniform5 | uniform4 |

## 保存されているもの

`result_logs/h1h3_pilot{,_seed1,_seed2}/`（各2.0MB）。探索は全層 × 全親 × 全候補の
スコアと落選枝を含む系譜（`h*_search_w*/search.json`）、評価は**塊単位の平均 NLL を
全件**と全引数（`*/summary.json`）。**seed ごとの生の PPL** と3本のまとめは
`result_logs/h1h3_pilot_seeds/seeds.{md,json}`。対応のある比較や信頼区間は、この
塊単位 NLL から GPU なしで後から計算できる。
