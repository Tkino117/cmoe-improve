## 問い

これまでの探索はどれも「1層展開して刈る」だった。刈る時点で見えているのは、その層を
足したときのスコアだけである。ここは幅を据え置いたまま**深さ**を1段増やす
（`--lookahead 1`）。子1つごとに次の層の候補を全部展開し、**その最良**を子の順位に
使う — 層 ℓ と層 ℓ+1 の依存を見てから刈ることになる。

## 設定

| | |
|---|---|
| モデル / 層数 | `meta-llama/Llama-2-7b-hf` / 32 |
| N / A | 8 / 6（スパース率25%） |
| 校正 | slimpajama n=16 × 2048（32,768トークン）、seed 0 / 1 / 2 |
| 採点オラクル / 探索 | `suffix_kl` / beam 幅2、深さ 0（対照）と 1（候補） |
| ルーター / 分割 | 現行 CMoE（k_act 10 / bias_speed 0.001） |
| ベンチ | PIQA / WinoGrande / ARC-e / ARC-c / HellaSwag、0-shot・全件、batch 32 |
| PPL | wikitext2 / c4-new |
| ブートストラップ | 10,000回 / seed 20260813 |
| dense の基準 | report/04 のものを取り込み |
| コード | `31b5c56`（3 seed とも clean な作業木で測った） |
| 所要 | 1 seed あたり 291分（探索 269分 + 測定 22分）、計 14.6時間 |

**校正・動作点・ルーター・評価・dense の基準は report/07 と同じ**で、動かしたのは
探索の深さだけである。対照の探索は測り直さず report/07 のものを読む。ベンチは
seed ごとに、対照と候補を**同じ実行の中で**測った。

`suffix_kl` の非決定性の床は3 seed とも 0.0、勝った配分の測り直しの差も 0.0 だった。
